## ✨ About

Gornergrat Station is a light theme for Omarchy that captures the serene, professional atmosphere of the famous Swiss alpine observatory at 3,089 meters above sea level. This theme brings the clarity of mountain air and the warmth of sunlit peaks to your desktop environment. The color palette is inspired by:

- The silver-gray of sun-bleached alpine stone
- Deep blue shadows cast by towering peaks
- The brilliant white of eternal snow
- The warm earth tones of exposed rock faces

The project is forked from the Rose Pine theme in Omarchy repository.

## 🚀 Installation

### Quick Install

Run in your terminal:

```bash
omarchy-theme-install https://gitlab.com/bhavabhuthi/omarchy-gornergrat-station-theme.git
```

Or use the Omarchy TUI: `Themes > Install`

Or Manual Installation:

1. Clone the repository:

```bash
git clone https://gitlab.com/bhavabhuthi/omarchy-gornergrat-station-theme.git
```

2. Copy the theme files to the Omarchy themes directory:

```bash
cp -r omarchy-gornergrat-station-theme ~/.local/share/omarchy/themes/
```
